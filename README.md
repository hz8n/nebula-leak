## ◆ What is this?
**Shadow Leak Sentinel** is a *standalone legendary* defensive terminal tool. No dependencies, single-file, offline, advanced CLI.
Built for Kali Linux. Use only on assets you own or have written permission to audit.

Legendary vibe: **◆ #00FF9D Shadow Leak Sentinel ◆** — each of the 70 projects has its own color/symbol/story. All designed by **al3rab**, fully in English.

## Install (10s)
```bash
git clone https://github.com/hz8n/nebula-leak.git
cd nebula-leak
chmod +x nebula-leak.py
./nebula-leak.py --help
./nebula-leak.py --target 127.0.0.1 --output report.json
```
